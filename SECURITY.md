# Security & Data Handling

## Synthetic data only

FedClear is a hackathon demonstration. **All data in this repository and in any demo
is synthetic / mock.** No real federal agency data, no real system inventory, no real
security findings, and no personally identifiable information are used anywhere in this
project. Do not commit real data to this repository.

## Not an accredited ATO tool

FedClear demonstrates an agentic *pattern* for ATO evidence adjudication. It is **not**
an accredited or authorized compliance system. Any real-world use in a federal
environment would require that agency's own Authority to Operate process, control
assessment, and accreditation. Nothing here substitutes for that.

## Reporting

This is a time-boxed hackathon project. For issues, open a GitHub issue. Do not include
sensitive or real data in issue reports.

## Dependency note

FedClear depends on the separately published open-source `ATLAS.Compliance.Logging`
library for evidence/audit primitives. That library is referenced as a dependency and is
governed by its own license and security posture.
